# Standards

Notes on specifications, protocols, and formats — external standards worth referencing and
adopting, as distinct from the practices we follow (`engineering/practices`) or the tools we use
(`tools`).

## Notes

- [Open Knowledge Format (OKF)](open-knowledge-format.md) — an open, vendor-neutral format for
  representing organisational knowledge as markdown + YAML for AI agents
- [Agent Interoperability Protocols](agent-interop-protocols.md) — the definitional anchor for
  vocabulary used across these notes without being defined: a boundary-to-contract map (Open
  Responses for models, MCP for tools, A2A between agents, AG-UI/A2UI for interfaces, AGENTS.md
  and Agent Skills in the repo, OTel GenAI for tracing, ACP for IDEs), the argument that these
  are independent contracts rather than one standard, and the incremental adoption order
  *(a September 2026 snapshot — the boundaries will outlast the spec names)*
